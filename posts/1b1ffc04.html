Arch Linux 安装

本文原发于 2018 年 11 月，最初参考了 LengQing 的 Arch Linux 安装笔记；当前版本按 2026 年 11 月官方 Installation guide / Arch Wiki 重写，命令行与默认选项以最新文档为准。

Arch Linux 把系统从空目录开始交给用户搭：引导器、内核、网络、桌面全部自选；遇到问题第一站永远是 Arch Wiki，答案质量极高；滚动更新意味着软件永远最新，代价是偶尔真的会把系统更新挂（所以别在服务器上无脑滚）。

安装方式有两种：官方的 archinstall 交互式安装器（省事，灵活，可在同一套配置里复用）和手动安装（本文主线，学会它才算真正会装 Arch）。

七、archinstall：一条命令的现代安装

如果手动流程只是日常使用、不想深究，Live ISO 自带的就是它：

最新 guided 安装器的行为要点：

  • 默认引导器已是 Systemd-boot（不再是 GRUB），并支持 UKI（Unified Kernel Image），对 Secure Boot / sbctl 更友好；
  • 交互菜单依次配置镜像、磁盘/分区（支持自动整盘、加密、btrfs 子卷）、引导器、主机名、root/普通用户、桌面环境（Plasma/GNOME/i3/Sway 等 profile）、内核、附加仓库和软件包；
  • 可先 --dry-run 生成配置预览：磁盘选择务必核对容量，别选成数据盘；
  • 同一套答案可复用：
  • ISO 制作后若 archinstall 有更新，Live 环境里先 pacman -Sy archinstall（官方允许 partial upgrade；内存足够时完整 pacman -Syu 更好）；
  • 它会把 ISO 里的网络配置（包括 Wi-Fi 密码）复制进新系统，注意别把测试网络带进生产机。

archinstall 适合快速交付一致环境，但手动流程仍值得亲手走一遍——出问题时你才知道该改哪个文件。

八、Secure Boot 与双系统

  • 安装阶段：官方 ISO 不支持 Secure Boot，先在 UEFI 里关闭；完善安装后可重新打开并用 sbctl 生成密钥、给引导器与内核签名（sbctl create-config、sbctl enroll-keys、sbctl sign）。UKI 模式（archinstall 可选）能让签名更集中；
  • Windows 双系统：复用现有 ESP，不要格式化；在 Windows 里关闭「快速启动」（powercfg /h off 可彻底关休眠），并将 Windows 时间改为 UTC 口径；GRUB 侧装 os-prober 并打开 GRUB_DISABLE_OS_PROBER=false，systemd-boot 则会自动生成 Windows 项；
  • BitLocker：如果 Windows 开了 BitLocker，换引导器或动 ESP 可能触发恢复密钥，先在 Windows 里读取并保存密钥。

九、故障排查

现象处理方向
重启后进不去，直接掉到 UEFI Shell启动模式不匹配（ISO 以 UEFI 启动却装了 BIOS 引导，或反之）；回到 2.1 复核
关了 Secure Bootstrap 也进不了 Live安装镜像不支持 Secure Boot；确认 UEFI 设置已保存，或换 U 盘/重写镜像
GRUB 里没有 Windows装 os-prober + fuse3，确认 /etc/default/grub 有 GRUB_DISABLE_OS_PROBER=false，重跑 grub-mkconfig；chroot 里探测异常就重启进系统再跑
根分区/ESP 挂载失败核对 /etc/fstab 的 UUID 与 blkid 输出；ESP 必须是 FAT32
pacman 报签名错误pacman-key --init && pacman-key --populate archlinux，再 pacman -S archlinux-keyring
iwctl 找不到 Wi-Fi 设备虚拟机/新网卡可能缺固件；先 device list 确认，插网线装 linux-firmware 或对应固件包
双系统时间错乱Windows 与 Arch 对 RTC 的解读不一致；统一 UTC 并关闭 Windows 快速启动
更新滚挂了先看 Arch News；用 pacman -Syu 前保留 linux-lts 作为备用启动项
archinstall 报磁盘/配置错先 --dry-run 检查生成的配置，确认磁盘容量与分区路径

十一、小结

手动流程按官方顺序只有十来步：确认启动模式 → 联网 → 分区格式化挂载 → pacstrap 装包 → fstab → chroot 配置 → 引导器 → 重启 → 初始化用户/网络/桌面。真正的门槛不是命令难记，而是每一步都要清楚「我现在在对哪块盘、哪个分区做什么」。日常想要可重复的环境，用 archinstall --dry-run 生成配置再复用即可。
