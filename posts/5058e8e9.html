中文分词之类的东西

受朋友之托，写一个小脚本，断断续续做了两天。朋友给的是一堆专业资料，内容枯燥难懂，想要一个"把全文关键词找出来并按重要程度排序"的工具，找不到现成的，就问能不能自己做一个。我也正好借机认识一下中文分词。

一、为什么需要分词

把全文关键词提取出来排序，前提是先把"词"识别出来。中文不像英文有空格天然划分词边界——中国人民银行 是"中国 / 人民 / 银行"还是"中国人民银行"，需要分词工具来判断。分词算法本身不是重点，直接用现成的：选型时对比了几个库，最后确定用 jieba（结巴分词），Python/JS 都有实现，社区词表也活跃。

jieba 有三种基础切分模式，值得知道：

模式方法特点
精确模式jieba.cut(text)最常用，试图切出最合理的词，无冗余
全模式jieba.cut(text, cut_all=True)把所有成词可能都扫出来，有冗余
搜索引擎模式jieba.cut_for_search(text)精确模式基础上，对长词再切分，适合检索

使用方法

  1. 把要处理的文本放到当前目录并重命名为 源文件.txt，按第二节初始化虚拟环境、pip install jieba；
  2. 执行 python keywords.py 生成 keywords.json，中途可以在 search.js 的 KEYWORDS 数组里填好要查的词；
  3. 执行 node search.js，结果写入 keywords_count.txt；
  4. 或者直接 ./main.sh（先 chmod +x main.sh）一键跑完。

5.2 繁体资料

朋友给的是繁体语料。jieba 的默认词典以简体为主，兼容繁体有两条路：

  1. 先转简：用 OpenCC 做 t2s（繁→简）转换后再分词，语义损失最小；
  2. 加载繁体词表：把 dict.txt.big 当用户词典加载（jieba.load_userdict("dict.txt.big")），让繁体词直接进词库——早期就是走的这条路。

六、专业词库从哪来：搜狗 scel 词库

新闻、医学、法律这类领域词，默认词库覆盖不足。搜狗输入法的「细胞词库」是公开的词库资源，格式为二进制 .scel，需要转成文本再喂给 jieba：

  • scel2txt——通用 scel 转 txt；
  • scel2mmseg——转成 mmseg 格式，可作为分词词典；
  • emoji-scel2txt——颜文字词库导出；
  • scel2pyim——转成 Emacs chinese-pyim 词库；
  • 更早的 sogou_hotwords_yong/scel2txt——当年就是从这里找到 scel 二进制解析思路的，代码是 Python 2 时代的写法，用/Python 3 跑需要小幅改造。

.scel 的结构大致是「全局拼音表 + 词组表」，词组表项为 (同音词数、拼音索引表、词长度、词字节、扩展信息（含词频）)，网上有详细注释。不过解析器属于一次性工具，维护成本高，优先用现成项目即可。
