正则表达式笔记

正则表达式（Regular Expression，常简写为 regex / regexp）是一种用单个字符串来描述、匹配一系列符合某个句法规则的字符串的模式。说简单点，就是按照某种规则去匹配符合条件的字符串。

本篇目标：

  • 理解正则表达式的基本语法；
  • 能在编辑器（VS Code / Vim / sed）中用正则完成复杂的查找与替换；
  • 能在 JavaScript 中使用 RegExp 处理字符串。

参考：DEERCHAO · 正则表达式 30 分钟入门教程

二、基础语法：元字符与量词

2.1 元字符

符号含义示例
.任意单个字符（默认不含换行）a.c 可匹配 abc、a c
^字符串（或行）开头^abc 匹配以 abc 开头
$字符串（或行）结尾abc$ 匹配以 abc 结尾
\转义符，或引出一个特殊字符类\. 匹配字面量点号
|分支条件，满足任一即可cat|dog 匹配 cat 或 dog

2.2 量词（重复次数）

符号含义示例
*前一元素重复 0 次或多次ab*c 匹配 ac、abc、abbc
+前一元素重复 1 次或多次ab+c 匹配 abc，不匹配 ac
?前一元素重复 0 次或 1 次ab?c 匹配 ac 或 abc
{n}前一元素恰好重复 n 次a{3} 匹配 aaa
{n,}前一元素至少重复 n 次a{2,} 匹配 aa、aaa…
{n,m}前一元素重复 n 到 m 次a{2,4} 匹配 2~4 个 a

2.3 字符类与分组

符号含义示例
[abc]匹配 a、b、c 中任意一个[aeiou] 匹配任意元音
[^abc]匹配除 a、b、c 以外的任意字符[^0-9] 匹配非数字
(exp)分组，同时捕获内容(ab)+ 匹配 ab、abab
(?:exp)分组，但不捕获(?:ab)+
(?<name>exp)命名捕获组(?<year>\d{4})

三、预定义字符类（最容易记反的部分）

字符等价于含义
\d[0-9]数字
\D[^0-9]非数字
\w[A-Za-z0-9_]单词字符（字母、数字、下划线）
\W[^A-Za-z0-9_]非单词字符
\s[ \t\n\r\f\v]空白符（空格、Tab、换行等）
\S非空白符非空白字符
\b—单词边界（\w 与 \W 的分界）
\B—非单词边界

需要注意：JavaScript 的 \w 不包含中文，汉字属于 \W；如果想要匹配中文，用 \p{Script=Han}（需 u 修饰符）或 /[\u4e00-\u9fa5]/。

四、贪婪与惰性匹配

正则默认是贪婪的：.* 会尽可能多地匹配。

贪婪匹配上述字符串时，会从第一个 <div> 一直吃到最后一个 </div>，一次吞掉整段：

模式类型效果
<div>.*</div>贪婪从第一个 <div> 匹配到最后一个 </div>
<div>.*?</div>惰性每次只匹配到最近的 </div>

在量词（*、+、?、{n,m}）后面加一个 ?，就会变成惰性匹配：

贪婪惰性含义
**?重复任意次，但尽可能少重复
++?重复 1 次或更多次，但尽可能少重复
???重复 0 次或 1 次，但尽可能少重复
{n,m}{n,m}?重复 n 到 m 次，但尽可能少重复

五、分组、捕获与引用

  • 捕获组 (exp) 会把匹配内容保存下来；
  • 在正则内部用 \1、\2 反向引用前面的分组；
  • 在替换字符串中用 $1、$2 引用（JavaScript、编辑器替换均如此）；
  • 命名捕获 (?<year>\d{4})，在替换中用 $<year> 引用。

零宽断言（环视）

零宽断言只判断位置，不消耗字符，因此可以排除掉某些上下文：

语法名称含义
(?=exp)正向先行断言后面必须紧跟 exp
(?!exp)负向先行断言后面不能紧跟 exp
(?<=exp)正向后行断言前面必须是 exp
(?<!exp)负向后行断言前面不能是 exp

六、修饰符（Flags）

修饰符名称作用
gglobal全局匹配；不加则找到第一个匹配即停止
iignoreCase忽略大小写
mmultiline多行模式，^ / $ 匹配每行的首尾
sdotAll. 也能匹配换行符（ES2018）
uunicode启用 Unicode 模式，正确处理代理对与 \p{...}
ysticky粘性匹配，从 lastIndex 位置开始且必须紧邻

7.1 两种创建方式

编辑器里写"查找替换正则"、配置文件里写正则字符串时，都按"构造函数"的规则来：\\d 才代表 \d。

7.2 常用 API

7.3 常见坑

  1. 反斜杠双重转义：new RegExp('\d') 里的 \d 会先被 JS 字符串处理掉，必须写 '\\d'；
  2. test() 的状态：带 g 的正则对象有 lastIndex，反复 test 同一字符串可能得到不同结果，需要时重置 reg.lastIndex = 0；
  3. 贪婪越界：.* 容易跨度过大，必要时用 .*? 或更精确的字符类；
  4. 不要解析完整 HTML：正则适合提取片段，嵌套结构请用 DOM / 专门的解析器。

八、常用实例速查

在 VS Code 中按 ⌘/Ctrl + H 打开替换，勾选 .*（正则）即可使用；Linux 命令行中 sed -E 's/pattern/repl/g'、grep -E 'pattern' 也是同一套语法。

十、小结

  • 先记住 6 个高频元素：. * + ? [] ()，其余都是组合；
  • \d \w \s 三兄弟永远是最常用的字符类，含义别记反；
  • 贪婪/惰性只差一个 ?；
  • 写完后一定在 regex101 / 编辑器里跑一遍，并考虑边界输入（空串、超长串、特殊字符）。
