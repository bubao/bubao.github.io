Linux 安装腾达 U12 无线网卡驱动

腾达（Tenda）U12 是一款性价比极高的 AC1300 双频 USB 3.0 外置无线网卡（支持 5GHz 867Mbps + 2.4GHz 400Mbps），其核心硬件方案采用的是经典广受好评的 Realtek RTL8812AU 芯片。

在 Windows 和 macOS 下，这款网卡几乎开箱即用或官网一键驱动即可点亮；但在 Linux 生态中，它却是许多极客的“噩梦”：

  1. 主线内核缺失：Linux Mainline 官方内核源码树至今未原生合入完善的 RTL8812AU 驱动；
  2. 官方驱动早已年久失修：腾达官网随附的 Linux 驱动停留在 Linux 3.x / 4.x 古早时代，在现代 Linux 5.x / 6.x 内核与现代 GCC 编译器下编译会直接触发上百行语法错误；
  3. 滚动更新陷阱（最致命）：很多教程教你无脑 make && sudo make install，而在 Arch Linux 这种滚动更新发行版上，只要下一次执行 pacman -Syu 升级了 Linux 内核，重启后网卡就会瞬间失联暴毙！

本文将针对现代 Linux 内核（以 Arch Linux、Ubuntu 为代表），详解现代社区驱动分支选型、DKMS 自动跟踪内核升级机制、USB 3.0 稳定性调优及断网排坑全指南。

二、上游驱动分支选型：告别僵尸仓库

网上很多老旧教程引用的 GitHub 仓库（如早期著名的 gnab/rtl8812au），早在近十年前就已经归档停止维护。如果强行克隆编译，会直接因内核 API 变更而崩溃报错。

目前开源社区主要有两个活跃维护的现代化分支：

驱动分支仓库维护团队核心优势推荐场景
aircrack-ng/rtl8812au安全审计社区主力维护完美适配 Linux 5.x ~ 6.x+，原生支持监听模式（Monitor Mode）与数据包注入（Frame Injection）🏆 首选推荐（兼顾日常高速上网与网络安全审计）
morrownr/8812au-20210629Linux 社区无线硬件极客专注家用网络吞吐性能、AP 热点模式与抗断连优化备选推荐（注重纯吞吐与信号稳定性）

本文以维护最活跃、受众最广的 aircrack-ng/rtl8812au 分支为核心基准展开。

在 Arch Linux 上执行完 pacman -Syu 后，磁盘上的内核文件和头文件已经升级到了全新版本，但内存中运行的依然是旧内核。此时若立刻执行编译，会提示找不到内核目录：

排坑解法：养成良好习惯：系统滚包更新内核后，必须先重启电脑（Reboot），再执行任何新驱动的编译或挂载操作。
