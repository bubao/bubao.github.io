ArchLinux 终端使用彩色 Emoji

在终端里正常显示彩色 Emoji，只需要两件事：装一个彩色 Emoji 字体，以及用支持彩色字形的现代终端。早期（本文 2017 年版本）依赖 cairo-coloredemoji、改写 glibc 的 charmaps 等 hack，如今都已没有必要——新终端自己会处理 Emoji 的宽度和彩色渲染。

感谢 hexchain 的 fontconfig 配置与 MaskRay 的 wcwidth 分析，原始思路来自 hexchain gist 和 Terminal Emulator Fullwidth Color Emoji。下文按当前 Arch 的推荐做法整理。

一、先理解：彩色 Emoji 从哪来

Emoji 的"彩色"不是终端画出来的，而是字体自带的位图 / 矢量彩色字形。常见格式：

  • CBDT/CBLC：位图彩色（Noto Color Emoji 使用，固定尺寸 128×128 等）；
  • COLR/CPAL：分层矢量彩色（Windows Segoe UI Emoji 使用）；
  • SVG-in-OpenType：内嵌 SVG（Twemoji 字体等）。

终端要支持彩色 Emoji，需要：

  1. 字体已安装，且 fontconfig 能找到它；
  2. 终端模拟器本身能渲染上述彩色字形（Pango、fontconfig/fcft、GPU 渲染器等）。

三、fontconfig 配置（多数终端可不做）

现代终端（kitty、WezTerm、foot、Alacritty、VTE 系）会通过 fontconfig 自动回退到已安装的 Emoji 字体，大多数情况下改完字体就能显示。只有老终端、或个别应用不回退时，才需要手动追加字体族：

保存为 ~/.config/fontconfig/fonts.conf，然后 fc-cache -f。几点提醒：

  • 只**追加（append）**Emoji 回退，不要把默认字体改成 Noto Color Emoji——它只有 Emoji 字形，没有字母；
  • 原文里 Noto Sans / Noto Serif 等默认字体设置，依赖对应字体的安装；按需保留，缺失时删除；
  • rgba / lcdfilter 是屏幕次像素抗锯齿参数，非 LCD 屏幕或显示异常时可去掉。

四、终端怎么选

终端彩色 Emoji备注
kitty支持（fontconfig 自动回退）GPU 渲染，开箱即用
WezTerm支持自带字体回退逻辑
foot支持Wayland，基于 fcft
Alacritty较新版本支持彩色字形旧版需自行升级
GNOME Terminal（VTE）/ Konsole支持经 Pango/Qt 直接渲染

也就是说：换成上述任一终端，九成场景不需要任何 Emoji 专有配置。

五、Emoji 宽度：现代终端自己算

Emoji 占两个字符宽度，是终端和渲染库的职责，不再是配置字体能决定的：

  • 确认 locale 是 UTF-8（locale 输出中 LC_CTYPE 为 *.UTF-8；Arch 默认 en_US.UTF-8 即可）；
  • kitty / WezTerm / foot / VTE 等都会按"宽字符"处理 Emoji；
  • 如果个别程序里 Emoji 宽度异常，先换终端验证，而不是先改系统 locale 数据。

旧文提到的 wcwidth hack——重新生成 /usr/share/i18n/charmaps/UTF-8.gz 覆盖系统文件、再用 pacman hook 保持——能强行让 glibc 的 wcwidth 认 Emoji 宽度，但会覆盖系统包管理的文件，存在升级后失效、影响其他程序的风险，今天不建议再使用。它只对依赖 glibc wcwidth 的终端（如部分 X11 程序）有意义，而这些场景现在基本都已被终端自身的宽度逻辑取代。

七、常见问题

现象原因 / 处理
Emoji 显示为黑白轮廓或方框字体没装或没刷新缓存；终端不支持彩色字形
彩色正常但宽度不对（错位）终端过旧；检查 locale 是否 UTF-8；换 kitty/foot/WezTerm
中文显示方块缺 noto-fonts-cjk，补装并 fc-cache -f
fc-match Emoji 无结果重装 noto-fonts-emoji；确认未装到 root 之外的路径
更新系统后配置"失效"旧的 charmap/pacman hook hack 会被升级覆盖；这也是不建议使用它的原因

八、参考资料

  1. Unicode UAX #11：East Asian Width —— Emoji 的宽度类别为 W；
  2. Unicode UTS #51：Unicode Emoji —— 变体选择符、ZWJ 与 Emoji 序列；
  3. Noto Emoji（GitHub） —— CBDT/CBLC 彩色字体；
  4. fontconfig 用户手册 —— 回退字体与匹配规则；
  5. kitty / WezTerm / foot / Alacritty —— 现代终端；
  6. HarfBuzz —— 字形整形与 Emoji 合成；
  7. Arch Wiki：Fonts；
  8. hexchain 的 fontconfig gist、MaskRay：Terminal Emulator Fullwidth Color Emoji —— 原始思路来源。

九、小结

现在要做的只有三步：装 noto-fonts-emoji（+ CJK 字体）→ 换一个现代终端 → 确认 locale 是 UTF-8。旧文里 cairo-coloredemoji、glibc charmap 重写之类的 hack 可以退休了；只有维护 URxvt 老环境时，才需要 libxft-bgra 和 fontconfig 追加 Noto Color Emoji 这两件事。
